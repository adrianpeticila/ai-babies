## Architecture & Core Modules

AI for Babies is a zero-dependency, ultra-fast, high-contrast engineering suite built with authentic brutalist UI principles (clean typography, crisp borders, light mode default with dark mode toggle). It includes 8 interactive modules:

1. **Prompt Engine** : Interactive diagnostic, template constructor, and real-time rubric optimizer for crafting production-ready system prompts.
2. **106-Term AI Dictionary** : Categorized, searchable, deep-dive reference covering Core LLM, Architecture, Agents, Inference, Data/RAG, Evaluation, Hardware/Ops, and Frameworks.
3. **RAG Interactive Visual Course** : Step-by-step interactive visualizer for document chunking, dense embeddings, vector search, cross-encoder reranking, context injection, and hallucination mitigation.
4. **AGENTS.md Multi-Agent Spec Engine** : Declarative multi-agent system prompt generator, boundary validator, and verifier contract builder.
5. **Speculative Decoding Speed Lab** : Interactive inference simulator demonstrating draft model speculation, parallel verification, acceptance rate mathematics, and latency speedups.
6. **Agent Gym Workspace Simulator** : Interactive agent playground featuring environment state transitions, ReAct execution loops, bash tool harness, and circuit breakers.
7. **WebMCP Tool Scanner** : Model Context Protocol discovery engine, JSON Schema inspector, and sandbox capability validator.
8. **Marketing Intelligence Layer** : Agentic ICP positioning matrix, Cialdini persuasion levers, competitor teardown, and GEO/AIO search readiness audit.

